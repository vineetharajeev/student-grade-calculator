# Student Grade Calculator 🎓

A simple Python program that calculates a student's total marks, average, grade, and pass/fail result.

## Features

* Calculates total marks
* Calculates average marks
* Assigns grades automatically
* Displays Pass/Fail result
* Uses Python conditional statements and user input

## Technologies Used

* Python

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run:

```bash
python grade_calculator.py
```

4. Enter the marks when prompted.

## Sample Output

```text

Enter mark for Subject 2: 90
Enter mark for Subject 3: 80

Total: 255.0
Average: 85.0

```
